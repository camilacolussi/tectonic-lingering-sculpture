# Working with this project

## About me
Beginner in physical computing, learning to work well with AI on creative
projects. Building a second, better version of an earlier installation,
now with more understanding of what I'm doing (previously had to ask for
help without understanding the "why").

## How I like to work — please follow this
- **Step by step, one stage at a time.** Don't jump ahead or solve later
  stages preemptively.
- **Explain the "why" before/alongside code**, not just working code with
  no explanation. I'm trying to build real understanding, not just get a
  working result.
- **Be honest about hardware/technical limitations up front**, even if it
  complicates the plan. Don't paper over a real difficulty to keep things
  simple — flag it, and explain the reasoning behind any workaround.
- **Ask before assuming** if a decision could go multiple ways — don't
  silently pick one.
- Log real decisions and reasoning into the relevant `notes.md` file for
  that stage as we go, not just in conversation — conversations get lost,
  files don't.

## Project context
